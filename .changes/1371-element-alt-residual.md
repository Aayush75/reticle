### Added

- **`@reticlehq/engine`: an `element` predicate can check an image's `alt` next to a locator that does not read it.** `{ kind: "element", query: { testid: "hero-image", alt: "Product photo" } }` was refused with "the element locator ignores `alt`", and so was `scope` + `self` + `alt`, so checking one attribute on one specific image meant a workaround. `alt` is now compared against the image's accessible name: a matching `<img>` passes, and a different alt grades `no` with the alt that was found. On an element that is not an image the predicate is still refused, now with a hint to assert `name` instead, because a button has no alt and "no" would read as "the alt is wrong". An `aria-label` on the image takes precedence over its alt as the accessible name. Closes [#1371](https://github.com/reticlehq/reticle/issues/1371).
